Exercise: Machine learning from scratch

Goal

After this exercise you will be able to:

  • Turn a biological question into a supervised learning problem: examples, features, labels, parameters.
  • Fit a logistic regression with glm, interpret its coefficients as log-odds and odds ratios, and fit the same model yourself by gradient descent.
  • Split data by chromosome, recognise overfitting, and control it with regularisation (glmnet) and cross-validation.
  • Compute a confusion matrix, precision, recall and FPR, and draw ROC and precision–recall curves by hand and in R.
  • Explain why class imbalance changes the PR curve but not the ROC curve, and why every model needs a baseline.

Background

Supervised learning. Each example (here a 500-bp window of the genome) has a label (open = 1, closed = 0) and a set of features computed from it (GC fraction, CpG observed/expected, motif counts). A model maps features to a prediction and has parameters that are chosen to make the predictions match the labels on the training examples. Its quality is measured on test examples that played no part in fitting.

Logistic regression. \(\text{score} = b_0 + b_1 x_1 + \dots + b_p x_p\) is the log-odds of being open; \(P(\text{open}) = 1 / (1 + e^{-\text{score}})\). A coefficient \(b\) adds \(b\) to the log-odds per unit of its feature, i.e. multiplies the odds by \(e^b\), with the other features held fixed.

Loss and fitting. The log-loss of one window is \(-\log p\) if it is open and \(-\log(1-p)\) if it is closed, where \(p\) is the predicted P(open). Fitting minimises the mean log-loss over the training set (= maximum likelihood). Gradient descent does this by repeated small steps against the slope; for logistic regression the slope for coefficient \(j\) is the mean of \((p_i - y_i)\,x_{ij}\).

Overfitting and regularisation. With many parameters and few examples a model can fit the training data perfectly and new data badly. Ridge (L2) and lasso (L1) add a penalty \(\lambda \sum b_j^2\) or \(\lambda \sum |b_j|\) to the loss; the lasso sets many coefficients exactly to 0. \(\lambda\) is chosen by cross-validation within the training set.

Metrics. At a threshold: TP, FP, FN, TN; accuracy \(=(TP+TN)/n\), precision \(=TP/(TP+FP)\), recall \(=TPR=TP/(TP+FN)\), \(FPR=FP/(FP+TN)\). Over all thresholds: the ROC curve (TPR against FPR; AUC = probability that a random positive scores above a random negative) and the PR curve (precision against recall; a random model sits at the fraction of positives).

Data

The exercise uses the GM12878 ATAC-seq peaks (ENCODE ENCSR095QNB, IDR thresholded peaks, GRCh38), the ENCODE blacklist, and the hg38 genome as a bgzipped, indexed FASTA (the same files as in Motifs, motif enrichment and TF footprinting). From the course repository:

data/download.sh ml-basics              # about 1 GB, mostly the genome
mkdir -p ~/epi/ml && cd ~/epi/ml

You need R with GenomicRanges, rtracklayer, Rsamtools, Biostrings, JASPAR2024, TFBSTools, RSQLite, motifmatchr (Bioconductor) and glmnet, pROC (CRAN); see Install the software you need. Building the data set (R1) takes one to two minutes; every other step runs in seconds, except R9 (about a minute). A laptop is enough.

Simplification. The labels are one cell line’s peak calls, the negatives are random genomic windows, and the features are five numbers chosen by hand. The next unit shows how the choice of negatives changes the answer; How a CNN reads DNA lets the model learn its own features from the sequence.

By hand

Do these on paper. A calculator is fine.

B1. Framing a prediction problem. A study predicts, for every CpG in blood, whether it is methylated (β > 0.5), from three numbers: the GC fraction of the 500 bp around it, whether it lies in a CpG island (0/1), and the log distance to the nearest TSS. It uses 400 000 CpGs measured on arrays in 10 people.

  1. What are the examples, the features and the label? How many parameters does a logistic regression with these features have?

  2. A 500-bp window has 130 C, 120 G and 18 CG dinucleotides. Compute its GC fraction and its CpG o/e \(= \#CG \times 500 / (\#C \times \#G)\). Another has 100 C, 105 G and 5 CG. Which looks like a CpG island?

  3. A colleague proposes adding a fourth feature: the methylation of the same CpG measured on the 450K array of the same person. Why is that a bad idea if the goal is to predict methylation where it has not been measured?

B2. Logistic regression. The five-feature model fitted in R7 is

\[\text{score} = -4.20 + 8.04\,\text{GC} + 0.97\,\text{CpG o/e} + 1.41\,\text{CTCF} + 0.60\,\text{SPI1} + 0.24\,\text{EBF1}\]

with motif features counting matches in the window.

  1. Compute the score and P(open) for a window with GC 0.45, CpG o/e 0.30 and no motif matches.

  2. The same window with one CTCF match. By what factor do the odds change? By what factor does the probability change? Why are these different?

  3. How many PU.1 (SPI1) matches raise the score as much as one CTCF match?

  4. By what factor do the odds change when GC rises by 0.1?

B3. Log-loss. A model predicts P(open) = 0.8 for an open window, 0.3 for a closed window and 0.1 for an open window.

  1. Compute the log-loss of each window (natural log) and the mean.

  2. Compare with a model that predicts 0.5 for everything. Which window is responsible for most of the first model’s loss?

B4. Confusion matrix. A classifier is tested on 1000 windows, 200 open and 800 closed. At its threshold it calls 250 windows open, of which 150 are truly open.

  1. Fill in TP, FP, FN, TN.

  2. Compute accuracy, precision, recall, FPR and \(F_1 = 2 \cdot \text{precision} \cdot \text{recall} / (\text{precision} + \text{recall})\).

  3. What accuracy does a “model” get that calls every window closed? What does this say about accuracy as a metric here?

B5. ROC and PR by hand. Eight test windows, sorted by score:

score 0.92 0.85 0.77 0.64 0.50 0.41 0.33 0.12
label open closed open open closed open closed closed

  1. Walk down the list and write the (FPR, TPR) point after each window. Draw the ROC curve.

  2. Compute the ROC AUC by counting (open, closed) pairs in which the open window has the higher score.

  3. At threshold 0.6, what are precision and recall?

  4. Compute the precision at the rank of each open window, and their mean (the average precision, an estimate of the PR AUC).

B6. Class imbalance. A model has TPR 0.8 and FPR 0.05 at its chosen threshold.

  1. On a balanced test set with 1000 open and 1000 closed windows: how many TP and FP, and what precision?

  2. Genome-wide, with 1000 open and 99 000 closed windows: how many TP and FP, and what precision?

  3. Does the ROC curve of the model change between (a) and (b)? Does its PR curve?

B7. Judge the design.

  1. Three models on the same data: A (2 features) training AUC 0.74, test 0.73; B (60 features) 0.86 and 0.79; C (5000 features) 1.00 and 0.61. Which overfits? Which would you choose?

  2. A student tries 40 feature sets, keeps the one with the highest test AUC (0.81), and reports 0.81 as the expected performance on new data. What is wrong, and what should they have done?

  3. A paper splits 1 million 200-bp genomic windows at random into 80% training and 20% test. Why might its test AUC be too optimistic? (Hint: how far apart are neighbouring windows, and are they independent?)

B8. Regularisation and cross-validation.

  1. A lasso and a ridge model are fitted to the same 256 4-mer features. One keeps 47 non-zero coefficients, the other 256. Which is which, and why?

  2. In 5-fold cross-validation on 36 000 training windows, how many windows is each model fitted on, and how many models are fitted to choose among 100 values of λ?

  3. Horvath’s methylation clock used elastic net on about 21 000 CpGs and selected 353. Why is regularisation essential when the number of CpGs is comparable to, or larger than, the number of samples?

In R

R1 — Build the data set: open and closed windows

suppressPackageStartupMessages({
  library(GenomicRanges); library(rtracklayer); library(Rsamtools); library(Biostrings)
  library(JASPAR2024); library(TFBSTools); library(RSQLite); library(motifmatchr)
})
D <- "/path/to/course/data"
fa   <- FaFile(file.path(D, "hg38.fa.bgz"))          # bgzipped + indexed genome
auto <- paste0("chr", 1:22)
bl   <- import(file.path(D, "hg38_blacklist.bed.gz"))
atac <- import(file.path(D, "gm12878_atac_peaks.bed.gz"), format = "narrowPeak")

# positives: 500 bp centred on the summit of each distinct peak (keep the strongest summit)
pk  <- atac[seqnames(atac) %in% auto]
pk  <- pk[order(-pk$signalValue)]
pk  <- pk[!duplicated(paste(seqnames(pk), start(pk), end(pk)))]
pos <- resize(GRanges(seqnames(pk), IRanges(start(pk) + pk$peak, width = 1)), 500, fix = "center")
pos <- pos[!overlapsAny(pos, bl) & countOverlaps(pos, pos) == 1]   # no overlapping windows
set.seed(1)
pos <- sort(pos[sample(length(pos), 20000)])

# negatives: random 500 bp windows, at least 500 bp from any ATAC peak, no blacklist, no N
len <- seqlengths(seqinfo(fa))[auto]
set.seed(2)
chr <- sample(auto, 60000, replace = TRUE, prob = len)
neg <- GRanges(chr, IRanges(floor(runif(60000, 1, len[chr] - 500)), width = 500))
neg <- neg[!overlapsAny(neg, atac, maxgap = 500) & !overlapsAny(neg, bl)]
neg <- neg[letterFrequency(getSeq(fa, neg), "N")[, 1] == 0]
neg <- sort(neg[1:20000])
c(positives = length(pos), negatives = length(neg))
# features: GC fraction, CpG observed/expected, and motif counts for three TFs
jdb  <- dbConnect(SQLite(), db(JASPAR2024()))
pwms <- do.call(PFMatrixList, lapply(c("MA0139.2", "MA0080.7", "MA0154.5"),
                                     function(id) getMatrixByID(jdb, id)))
names(pwms) <- c("ctcf", "spi1", "ebf1")
features <- function(gr) {
  s  <- getSeq(fa, gr)
  L  <- width(s)
  nc <- letterFrequency(s, "C")[, 1]; ng <- letterFrequency(s, "G")[, 1]
  cg <- vcountPattern("CG", s)
  mc <- as.matrix(motifCounts(matchMotifs(pwms, s, p.cutoff = 5e-5, bg = "even", out = "scores")))
  colnames(mc) <- names(pwms)
  data.frame(chrom = as.character(seqnames(gr)), start = start(gr) - 1, end = end(gr),
             gc = (nc + ng) / L, cpg_oe = cg * L / pmax(nc * ng, 1), mc)
}
dat <- rbind(cbind(features(pos), open = 1), cbind(features(neg), open = 0))
saveRDS(dat, "ml_atac.rds")
head(dat, 3)

This takes one to two minutes. It is the only step that needs the genome; everything after it reads ml_atac.rds.

  1. Explain each filter applied to the positives and to the negatives. Why are negatives kept at least 500 bp away from any ATAC peak, and why are windows that overlap another window dropped?

  2. Why is the summit start(pk) + pk$peak and not start(pk) + pk$peak + 1? (Recall Genomic intervals, R1.)

  3. Look at the three rows printed. Compute GC and CpG o/e for a window yourself from getSeq(fa, ...) for the first row and check them against the table.

The motif features are deliberately counts of matches at a strict cutoff (motifCounts, p < 5 × 10⁻⁵). If you want a continuous motif score instead, use motifScores with p.cutoff = 1: with a strict cutoff every window without a match gets score 0, and the ranking is lost (see What people try to predict, and how to tell if it works, R2, and How a CNN reads DNA).

R4 — Fitting by hand: gradient descent

X <- cbind(1, train$gc)                        # design matrix: intercept and GC
y <- train$open
sigmoid  <- function(z) 1 / (1 + exp(-z))
log_loss <- function(b) { p <- sigmoid(X %*% b); -mean(y * log(p) + (1 - y) * log(1 - p)) }

b  <- c(0, 0)                                  # start somewhere
lr <- 5                                        # learning rate: the step size
for (i in 1:2000) {
  grad <- crossprod(X, sigmoid(X %*% b) - y) / nrow(X)   # slope of the loss
  b    <- b - lr * grad                                  # step downhill
  if (i %in% c(1, 10, 100, 500, 2000)) cat(i, round(b, 3), round(log_loss(b), 4), "\n")
}
c(gradient_descent = b, glm = coef(m1))

  1. How does the loss change over the iterations? After how many steps are the coefficients within 0.01 of glm’s?

  2. Rerun with lr <- 50 and with lr <- 0.5. What happens in each case, and why?

  3. The loss at the start, with both coefficients 0, is 0.693. Why exactly that number?

R5 — From probabilities to calls: the confusion matrix

call <- as.integer(p1 >= 0.5)

        precision = TP / (TP + FP),
        recall    = TP / (TP + FN),
        FPR       = FP / (FP + TN)), 3)

  2. Change the threshold to 0.3 and to 0.7. Which metrics go up and which go down?

R6 — ROC and precision–recall curves, coded by hand

curves <- function(score, label) {
  o  <- order(score, decreasing = TRUE)         # walk down the ranked list
  s  <- score[o]; l <- label[o]
  tp <- cumsum(l); fp <- cumsum(1 - l)
  k  <- c(diff(s) != 0, TRUE)                   # tied scores: one threshold, one point
  data.frame(threshold = s[k], tpr = tp[k] / sum(l), fpr = fp[k] / sum(1 - l),
             precision = tp[k] / (tp[k] + fp[k]))
}
auc_roc  <- function(cv) sum(diff(c(0, cv$fpr)) * (cv$tpr + c(0, head(cv$tpr, -1))) / 2)  # trapezoids
avg_prec <- function(cv) sum(diff(c(0, cv$tpr)) * cv$precision)   # area under the PR steps
c1 <- curves(p1, tst$open)
c(ROC_AUC = auc_roc(c1), PR_AUC = avg_prec(c1))
pROC::auc(tst$open, p1, quiet = TRUE)                          # check with a package
par(mfrow = c(1, 2))
plot(c1$fpr, c1$tpr, type = "l", xlab = "FPR", ylab = "TPR", main = "ROC"); abline(0, 1, lty = 2)
plot(c1$tpr, c1$precision, type = "l", xlab = "recall", ylab = "precision", main = "PR", ylim = c(0, 1))
abline(h = mean(tst$open), lty = 2)

  1. What are the ROC AUC and PR AUC of the GC model? Does your ROC AUC agree with pROC::auc?

  2. Ties: GC is a count divided by 500, so many windows have exactly the same GC. Remove the line k <- c(diff(s) != 0, TRUE) (and the [k]s) to break ties by row order instead, and recompute. Why does the AUC go up? (Look at the order of the rows in dat.)

  3. Where on the PR plot does the dashed line sit, and what does it represent?

  2. Look at plot(lasso): which λ does cross-validation choose, and how does the curve behave at the extremes?

  3. The second chunk uses all 36 317 training windows. Compare its test ROC AUC with the five-feature glm of R7. Which of the two would you report as your model, and with which baseline next to it?

Hints

Hint 1 — logistic regression (B2, R3, R7)

\(P = 1/(1 + e^{-\text{score}})\); odds \(= P/(1-P) = e^{\text{score}}\). Adding \(b\) to the score multiplies the odds by \(e^b\), whatever the starting point; the change in probability depends on where you start. In R, glm(..., family = binomial) fits the model and predict(..., type = "response") returns probabilities (the default, type = "link", returns the score). A friendly introduction: chapter 4 of An Introduction to Statistical Learning, free online.

Hint 2 — loss and gradient descent (B3, R4)

Use natural logarithms: \(-\log(0.5) = 0.693\). In gradient descent the step is learning rate × slope: too large and each step jumps over the valley to a higher point on the other side; too small and progress is slow. crossprod(X, r) is \(X^\top r\).

Hint 3 — confusion matrix and curves (B4–B6, R5, R6, R10)

Write the 2 × 2 table first, with row sums P and N. ROC: each open window moves the curve up by \(1/P\), each closed window right by \(1/N\). AUC by pairs: for each open window, count the closed windows with a lower score; add up; divide by \(P \times N\) (a tie counts ½). Precision depends on how many closed windows there are; TPR and FPR do not. Background: Saito & Rehmsmeier 2015; pROC::auc.

Hint 4 — overfitting, regularisation, CV (B7, B8, R8, R9)

Count parameters (one per feature, plus the intercept) and compare with the number of training examples. cv.glmnet fits the lasso (alpha = 1) or ridge (alpha = 0) for a sequence of λ values on each fold; foldid sets which fold each example belongs to; s = "lambda.min" uses the λ with the best cross-validated score. See the glmnet vignette.

Hint 5 — building the data (R1)

resize(..., fix = "center") makes a window around a point; overlapsAny(..., maxgap = 500) counts ranges within 500 bp as overlapping; getSeq on a FaFile reads only the windows you ask for; letterFrequency, vcountPattern and oligonucleotideFrequency count letters, a pattern and all k-mers; matchMotifs scans PWMs as in Gene regulation.

Parameters: 4 (intercept + one per feature). Note that all three features are the same for every person: such a model can predict which CpGs are methylated, but nothing about differences between people. (b) GC \(= 250/500 = 0.50\), CpG o/e \(= 18 \times 500 / (130 \times 120) = 0.58\): close to the classic CpG island criteria (GC > 0.5, o/e > 0.6). The second: GC 0.41, o/e \(= 5 \times 500 / (100 \times 105) = 0.24\), typical bulk genome. (c) The feature is a measurement of the label itself. B2. (a) \(-4.20 + 8.04 \times 0.45 + 0.97 \times 0.30 = -0.29\); \(P = 1/(1 + e^{0.29}) = 0.43\). (b) Score \(-0.29 + 1.41 = 1.12\), \(P = 0.75\). B7. (a) C overfits badly (perfect training, worst test); B overfits a little (gap 0.07) but generalises best. Choose B, but the choice should be made on validation data or by cross-validation, keeping the test set for the final number. (b) The test set has become part of model selection: picking the best of 40 rewards luck as well as quality, so 0.81 is optimistic. Select with cross-validation or a validation set, then evaluate the single chosen model once on the test set. (c) Neighbouring windows overlap or share their surroundings (same peak, same domain, similar GC), and their labels are correlated. A random split puts near-copies on both sides, so the test set is not new. Split by chromosome (or by region).

B8. (a) The lasso keeps 47: the absolute-value penalty has a corner at 0, so it sets weak coefficients exactly to 0. Ridge shrinks all 256 towards 0 but none to exactly 0. (b) Each fit uses 4/5 of the data, 28 800 windows; 5 folds × 100 λ = 500 fits (glmnet computes each fold’s whole λ path in one go), plus a final fit on all training data at the chosen λ. (c) With as many or more CpGs than samples, there are infinitely many coefficient vectors that fit the training data perfectly; the penalty picks a small, stable one and, with L1, a short list of CpGs. Neighbouring CpGs are also strongly correlated, which makes unpenalised coefficients unstable.
